# KADAFI Ben — Interactive résumé

Interactive résumé of **KADAFI Ben**, full-stack developer (TypeScript · React · Vue 3 · Laravel · NestJS · PostgreSQL).

**Live:** https://kadafi-ben-cv.vercel.app · **Portfolio:** https://kadafi-ben.vercel.app

- Bilingual FR / EN, light / dark theme
- Downloadable PDF résumé in the selected language (`public/cv/fr`, `public/cv/en`)
- All content lives in `src/data/resume-config.ts`

## Scripts

```bash
npm install
npm run dev      # local dev server
npm run build    # typecheck + production build
```
